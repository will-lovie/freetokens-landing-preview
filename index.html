02 — Definition

What is a local token vault?

A local token vault stores free LLM API keys as records on this Mac, instead of a pile of dashboards you paste from. You harvest once. Chat, agents, and file edits run on those keys. Lovie does not keep a copy.

  • Each provider is its own record. Collected or idle is a fact, not a spreadsheet you maintain.
  • Get Tokens walks the automatic providers in the app's own browser and writes keys to the macOS Keychain.
  • Chat is one surface. Folder and files attach as context. You press Apply on every edit.

09 — Questions

Answers before you ask.

Does harvest run in the browser?

No. This page is a sample with fake keys. Get Tokens runs in the Mac app, in its own browser, on your machine.

Where do keys live?

On this machine, in the macOS Keychain. Not on Lovie servers. An older keys.json file imports on first run.

Do I need an account?

Sign in with your Lovie account to open the app. You still sign up at the providers for the tokens themselves. Lovie does not issue the keys.

Apple Silicon or Intel?

Apple Silicon is the current download. 1.1.0 does not ship a separate Intel dmg.

Will Gatekeeper block it?

The dmg is signed and notarized. Open it and drag FreeTokens to Applications. If macOS nags anyway, check the sha256 on the Download section against the file you got.

Does Apply write my files?

Only when you press Apply, in the Mac app. This landing demo never writes to disk. Diffs stay in the thread until you say so.

What are Agents?

Named teammates on the same Chat. Attach SKILL.md playbooks. Opening one lands in Chat with folder, files, and skills. Create stays on the roster. You press Apply on edits.

Is this Accelerator Apply?

No. FreeTokens is the Mac vault and Chat. Accelerator Apply is a sibling. It is not on this page.
